# 🤖 AI Study Assistant

An AI-powered Study Assistant that helps students learn smarter by summarizing notes, answering questions, and generating quizzes from uploaded study material.

## ✨ Features

- 📄 Upload PDF notes
- 📝 AI-powered summaries
- ❓ Ask questions about your notes
- 🧠 Quiz generation
- 📊 Study dashboard
- 🔐 User authentication
- 📚 Chat history

## 🛠️ Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python

### AI
- Google Gemini API

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/tanmay-d-s/AI-Study-Assistant.git
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
